# Engineering Studio and continued PatentRadar delivery

Local implementation, 2026-10-25. This is a working constrained engineering MVP, not unrestricted reverse engineering of arbitrary drawings. No deployment occurred in this execution.

## What is operational

- Existing PDF extraction, public search, source links, lexical ranking, claims fallback, streaming and report export preserved.
- **BigQuery substitute:** SQLite FTS5 local public-patent index. Real records returned by existing authorized providers are indexed with original provenance. A local-only mode runs without external queries or Google credentials. Offline import tool accepts authorized normalized JSONL and an explicit licence/attribution argument. It does not supply an entire worldwide corpus. OpenAIRE/EPO remain the connected discovery/retrieval sources; no undocumented Google scraping was enabled.
- **Lot B, bounded implementation:** source-validated AI claim quotes with exact offsets, AI candidate ranking rejecting invented identifiers, and explicitly labeled translation preserving original text. UI in AI Comparison. Requires OpenAI configuration, consent and an account. These paths were fixture-tested, not live AI-certified. Lexical fallback remains available. No expert relevance benchmark, complete legal-status retrieval or semantic-index claim is made.
- **Lot C, bounded implementation:** local-server accounts, scrypt passwords, hashed expiring HttpOnly/SameSite sessions, per-user portfolios, component catalogs, explicit project reopening, manual saved watches, newly discovered record counts, downloadable personalized source briefings, daily request allowances and authenticated read-only MCP tools. Tokens are hashed, 24-hour scoped and rejected outside MCP. SQLite tenant isolation is tested. Billing, verified-email recovery, scheduled monitoring and automatic email delivery are NOT implemented. No fake balance or paid credit is shown.
- **Engineering input:** PDF, PNG/JPEG, pasted measured specifications, STEP and STL. PDF text uses up to first 20 pages and rendered images up to first 4; maximum PDF 80 pages / 4 MB file. Full source coverage is disclosed. No image AI occurs without consent and configuration.
- **Interpretation:** local rules recognize explicit mm box dimensions and shaft/tube dimensions. Multimodal Responses API can propose boxes/cylinders/tubes or unresolved components, with page, quote, material, relationships and nullable dimensions. Text quotes are checked and unsupported numerical values removed. Visual evidence is explicitly unverified. AI-free mode uses real supplied measurements, not a seeded assembly.
- **Geometry:** real CadQuery 2.6.1 solids for boxes, cylinders and tubes/bores. Required measurements must be supplied. STEP assembly and STL exports, volume/validity and tessellation generated by OpenCascade. Parametric measurements and transforms editable. Native worker never executes model-generated code; subprocess limited to two concurrent jobs, timeout/output/file bounds and CPU limit.
- **Viewer/assembly:** orbit/zoom, raycast selection, axis dragging, numerical position/rotation, hide/show, isolation, exploded visualization, duplication/removal and rotation preview. STEP imports preserve solids and can be repositioned/reexported. STL is inspectable mesh only; no feature tree or solid STEP conversion is invented.
- **Catalog:** source filename/hash and page/quote, dimensions/material, relationship notes, primitive parameters and component mesh preview can be saved privately. Assemblies reopen from parameters and rebuild. Original PDF/image binaries are processed transiently and not retained; the catalog is not an original-document archive.
- **Patent connection:** selected component descriptions are handed to the existing editable invention profile → consented patent research journey. Patent associations are not automatically persisted back to each catalog component yet.

## Reproduce locally

```bash
npm ci
python3 -m venv .venv-cad
.venv-cad/bin/pip install -r cad/requirements.txt
npm run build
CAD_PYTHON="$PWD/.venv-cad/bin/python" npm run start
```

This workspace has the tested Python environment at `/workspace/cad-venv/bin/python`; it is not committed. Node 24+ required for node:sqlite. SQLite defaults to private `.data/`; set PATENTRADAR_DATA_DIR to a persistent server volume for deployment. Use HTTPS when serving accounts remotely. Do not place a writable SQLite database on ephemeral serverless storage and call it persistent hosting.

1. Open Engineering Studio in the top navigation.
2. Upload an actual technical PDF or paste measured component specifications. For automated verification, `tests/fixtures/mechanical-dimensions.pdf` is explicitly a test fixture, not a production demo.
3. Click Read document & identify parts. Review source pages/quotes and nullable dimensions. Add missing measured values; do not infer them from an unscaled image.
4. Rebuild CAD, inspect parts, move/rotate, then rebuild to update exports. Exploded display and rotation preview do not alter export coordinates.
5. Export STEP/STL or editable parameters. Use Review features for patent research to enter the existing reviewed/consented search flow.
6. Under Account, create a local account; save parts/assemblies privately. Load catalog in the Studio to search, duplicate/reuse or reopen.

## Optional configuration

OPENAI_API_KEY and OPENAI_MODEL enable multimodal interpretation / assisted review after consent. None were available locally for a real AI call. AI_DAILY_CALL_LIMIT counts new assisted-review/CAD requests, not money; legacy document extraction has its prior behavior and is not included in that counter. There is no global USD cost ledger. LIMITs on inputs/outputs keep individual calls bounded.

ENABLE_BIGQUERY stays false by default; its previous adapter is retained. The local index avoids that prerequisite. Import your authorized records with:

```bash
node scripts/index/import-patents.mjs /path/authorized-public-records.jsonl 'actual source licence and attribution'
```

Required normalized record fields: publicationNumber with kind, title, applicants, source, sourceUrl and retrievedAt. Do not import confidential invention profiles into the public patent index. Bulk datasets require rights and normalization; the importer does not turn a portal into an anonymous API. EPO explicitly recommends downloading bulk Linked Open Data for production indexing: https://www.epo.org/en/searching-for-patents/data/linked-open-data . It does not provide global full-text or a guaranteed anonymous worldwide replacement.

## Hosting

A Dockerfile is supplied for Next.js + Python/CadQuery and a private persistent volume. It was not built or deployed here; only the equivalent native runtime was tested. Typical command after reviewing image/licence dependencies:

```bash
docker build -t patentradar-engineering .
docker run --rm -p 3000:3000 -v patentradar-data:/var/lib/patentradar patentradar-engineering
```

The existing plain Vercel Next.js deployment has neither this Python environment nor a persistent SQLite volume. Do not deploy the frontend alone and claim cloud CAD/accounts are operational. Use a native/container backend with persistent storage or adapt to an authorized remote worker and managed database before cloud rollout. Existing cloud patent search remains separate from this local delivery.

## Explicit reconstruction limits

Complex surfaces, gears/tooth profiles, arbitrary holes/fillets, assembly constraints, collision/fit solving, load/stress simulation, exact feature recovery from STEP, general OCR and manufacturing tolerances are not implemented. Primitive topology may be only an approximation even with measured bounding dimensions. All generated geometry requires engineering validation. Connections are notes, not solved joints. No missing dimensions are silently invented. Imported meshes are not labeled validated solids. No FTO or infringement conclusion is generated.

## Browser runtime update — current 3D entry point

The studio now runs Replicad 1.2.0 / OpenCascade WASM in a dedicated browser worker. Open `/engineering`: no account, API key or Python is required to generate measured box/cylinder/tube geometry, import STEP, edit placements and export STEP/STL. This supersedes the earlier native-only hosting requirement for the interactive studio. Native authenticated CAD APIs still use the optional Python worker.

PDF text extraction now uses the existing pdfjs server runtime, preserving text lines/pages and source quotes without a Python dependency. Optional rendered PDF images for multimodal analysis still require a configured native image renderer; PNG/JPEG input is supported by configured consented AI paths. No image-only or missing geometry is silently reconstructed.

CAD computation takes place on the user's device. The unmodified 22 MB WASM runtime is self-hosted and prepared during npm install from pinned dependencies; no confidential dimensions are sent to a third-party CAD service. Device-local catalog saves and parameter export work without server accounts. Device storage is separate from authenticated private server storage and is labeled accordingly.

The real browser test now runs with no CAD_PYTHON environment variable and verifies original and changed solid volumes as well as STEP download. Exported geometry is still a primitive approximation, not a manufacturing certification or solved joint simulation.
