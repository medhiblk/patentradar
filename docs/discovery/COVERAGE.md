# Jurisdiction and capability gaps

This is a dated audit of specific services, not proof that no other public API exists. Search snapshots include all eleven requested languages. A public search website is not classified as an anonymous API. Existing paid/credentialed integrations remain optional and are not counted as free sources.

## Remaining functional limits

- **Patent search:** OpenAIRE is a literature-linked subset of Lens-derived metadata. It can include recent US/CN/JP/KR/WO records but gives no completeness guarantee for any jurisdiction. Europe PMC's legacy patent archive remains available only behind an explicit policy opt-in.
- **Claims/drawings:** Exact EPO publication XML/PDF is implemented. Worldwide claims and drawing retrieval is not guaranteed. VeyIP and public Google publication-page adapters are not enabled by default under this strict licensing audit.
- **Families:** Family grouping uses only explicit source family IDs. EPO's verified linked reference record exposes a family URI but is disabled as an automatic production backend. OpenAIRE deduplication is not treated as a patent family.
- **Citations:** OpenCitations supplies scientific DOI citations. They are not relabelled as patent citations. OpenAIRE documents patent-to-paper relationships, but this release does not claim a complete patent citation graph.
- **Legal status / FTO:** Third-party MCP legal labels are not promoted to verified legal status. No source network establishes infringement, validity or legal clearance.
- **Identity:** ROR, GLEIF, Wikidata and French company identifiers support human-reviewed entity resolution. Name/alias matches do not prove ownership or inventor identity.
- **Languages:** Unicode/NFKC normalization and CJK/Korean token handling are implemented. Source coverage and search language remain provider-dependent. No complete automatic cross-language semantic retrieval is claimed.
- **Scale:** Public quotas are real. Local rate limiting, caching and in-flight deduplication are process-local. Multi-instance production needs a shared limiter/cache or a bulk-data index; do not multiply machines/IPs to evade quotas.
- **PDF export:** the current report font is basic Latin; non-Latin glyphs can be substituted. API/JSON records retain Unicode. A Unicode PDF font is still needed before claiming complete CJK report rendering.
- **Monitoring:** Metadata APIs and datasets are candidates for dated incremental ingestion. No new legal-status monitoring/alert service is claimed in this discovery release.
