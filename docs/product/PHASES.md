# Invention workspace and seed discovery

Implemented: optional title, description-first project entry, local-device saving/deletion/reopening, analysis handoff with existing consent and editable extracted features, multiple normalized publication references, country/kind recognition and Google reference links on sourced results. No project upload occurs when saving locally. Browser storage is not authenticated cloud isolation and is not suitable for a shared device.

Google Public Datasets: upstream https://github.com/google/patents-public-data . BigQuery access remains disabled pending a configured project, query permissions and a reviewed cost budget. Do not infer current table freshness from the repository release date. The publications schema includes localized text, citation and family fields, but populated fields and coverage must be checked against actual table metadata before synchronization. No BigQuery query or freshness check was executed in this change. Google reference links are generated from identifiers and do not verify document existence. Existing source attribution is preserved.

Not yet implemented in this change: authenticated accounts, billing/credits, cloud-private project storage, automatic watches/newsletters, new seed metadata lookup, seed-derived semantic search, multi-hop patent citation graph, claims enrichment or authorized local dataset synchronization. Existing source-specific retrieval remains available. Citation adjacency must not be scored as technical equivalence. A subsequent implementation must store typed source-backed edges and distinguish missing evidence from zero citations.
